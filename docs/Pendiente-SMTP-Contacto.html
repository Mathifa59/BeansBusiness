Pendiente business-beans · app/api/contacto

Configuración SMTP del formulario de contacto

El código ya está migrado de Resend a SMTP propio. Falta un solo paso: las credenciales del buzón que va a enviar los correos.

Qué pasó

El envío ya no depende de Resend

En un pull reciente se migró el formulario de contacto de Resend a SMTP autenticado, usando el buzón propio del cliente (comercial@businessbeans.com.pe). El código en app/api/contacto/route.ts y lib/mail/transporter.ts ya está listo, con honeypot anti-spam y límite de envíos por IP incluidos.

Qué falta

Las variables de entorno nunca se configuraron

.env.local todavía tiene las variables de la época de Resend, que el código actual ya no lee. Necesita estas cinco:

# .env.local — y las mismas 5 en Vercel SMTP_HOST= SMTP_PORT=465 SMTP_USER= SMTP_PASS= MAIL_TO=

Sin esto, el formulario responde bien en pantalla pero el envío del correo falla en silencio del lado del servidor.

Qué necesito de ti

Tres datos para cerrar esto

  • 1 Dónde está alojado comercial@businessbeans.com.pe Google Workspace, Microsoft 365, o el panel de hosting/dominio donde se creó el correo — define el host y puerto SMTP correctos.
  • 2 La contraseña de esa cuenta Si tiene verificación en 2 pasos (Gmail/Workspace), hace falta generar una "contraseña de aplicación" — la contraseña normal de login no funciona para SMTP.
  • 3 A qué correo(s) deben llegar los mensajes Puede ser el mismo comercial@... u otra dirección interna del equipo comercial.

Dónde pegarlo

Local y producción

Local: las 5 variables van en .env.local, en la raíz del proyecto.

Producción: Vercel → proyecto beans-business → Settings → Environment Variables → agregar las mismas 5, entorno "Production". Eso lo tienes que hacer tú directamente en el panel de Vercel, por seguridad de la contraseña.
